# OrderFlow

A portfolio order management system built to demonstrate full-stack development,
API troubleshooting, database integration, and diagnostic logging.

## Planned stack

- Frontend: React
- Backend: C# and ASP.NET Core Web API
- Data access: Dapper
- Database: SQL Server
- Testing: automated API and frontend tests

## Development philosophy

Build it. Break it. Diagnose it. Fix it. Prove it's fixed.

All project data will be synthetic.
